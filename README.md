## What I'm building

### TrustIntern

A scam detective for internship and job offers. Paste in an offer and TrustIntern checks the company, recruiter, website and message, then gives an explainable risk score. The score is a heuristic indicator, not a probability of fraud.

- [Try TrustIntern live](https://trustintern.charancodes.com)
- [Read the TrustIntern source code](https://github.com/compteccharan/TrustIntern)
- [Read how I built it in my DEV post](https://dev.to/noahosmont/trustintern-i-built-a-scam-detective-for-internship-offers-in-55-hours-and-my-agents-kept-1446), my entry for the DEV Hacktoberfest Open-Source AI Challenge

Built with Python, FastAPI, React with Vite, Ollama running Gemma, Vercel and GitHub Actions. It has tests, CI and a demo video.
